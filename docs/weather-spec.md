# Canonical Weather Specification Entry Point

The normative weather contract is maintained by the meteorology domain at:

[`docs/meteorology/weather-spec.md`](meteorology/weather-spec.md)

This compatibility entry point intentionally contains no duplicate field
definitions. Changes to weather field meanings, units, record types, provenance,
or QC rules must be made in the normative meteorology handoff and reviewed by
the owning domain.
