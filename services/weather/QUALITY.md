# Weather Quality Checks

This runbook covers only the meteorology-owned Python package under
`services/weather`. Run every command from the Everest repository root.

## Prerequisites

- Python 3.11 or later.
- Black, Pylint, pytest, and the runtime dependencies used by the weather tests.
- The owner-neutral shared contract from this workspace. Install it into the
  active environment with:

  ```powershell
  py -m pip install -r services/weather/requirements-local.txt
  ```

  This is an editable local-project install. It does not install or package
  backend code. As a non-installing alternative for a clean checkout, set the
  project import roots for the current PowerShell process:

  ```powershell
  $env:PYTHONPATH = ".;packages/weather_ingestion_contract"
  ```

Do not disable Pylint's `import-error` check. A missing
`weather_ingestion_contract` import means that the local prerequisite or the
explicit project `PYTHONPATH` is absent and must be corrected.

## Clean invocation

From the repository root, after satisfying the prerequisite above:

```powershell
$env:PYTHONPATH = "."
py -m black --config services/weather/pyproject.toml --check services/weather
py -m pylint --rcfile services/weather/pyproject.toml services/weather
py -m compileall -q -f services/weather
py -m pytest -q services/weather/tests
```

The project-root `PYTHONPATH` lets Pylint resolve the package's required
`services.*` absolute imports while it scans a filesystem directory. It is not
an error suppression. The shared contract remains supplied by the editable
local install above. The explicit configuration path makes the 80-column
requirement independent of the caller's global Black or Pylint configuration.
`compileall` writes generated bytecode under `__pycache__`; those directories
and `.pytest_cache` are safe to remove after evidence collection, but source
files and retained raw artifacts must never be removed as quality cleanup.
